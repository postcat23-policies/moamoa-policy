모아모아(moamoa) 계정·데이터 삭제 요청

시행일: 2026년 10월 26일 · 개발자: postcat23

본 페이지는 모아모아(moamoa) 앱의 계정 및 관련 데이터 삭제를 요청하는 방법을 안내합니다. 모아모아는 개인 개발자가 운영하는 모임 계획 서비스입니다.

1. 앱 내에서 직접 삭제 (권장)

앱을 사용할 수 있는 경우, 가장 빠른 방법은 앱 내 삭제입니다.

  • 모아모아 앱에서 설정 > 계정 삭제로 이동합니다.
  • ‘삭제된 데이터는 복구할 수 없습니다’ 안내에 동의하면 즉시 삭제가 실행됩니다.
  • 운영자의 별도 승인·검토 없이 실행 즉시 처리됩니다.

2. 웹에서 삭제 요청 (앱을 사용할 수 없는 경우)

앱을 이미 삭제했거나 접근할 수 없는 경우, 아래 요청 양식을 통해 재설치 없이 계정·데이터 삭제를 요청할 수 있습니다.

계정 삭제 요청 양식 열기

모아모아는 카카오 로그인만 사용하며 이메일 주소를 수집하지 않습니다. 따라서 요청하신 계정을 정확히 특정하기 위해 양식에서 카카오 닉네임과 회신 받을 연락처를 입력해 주시기 바랍니다. 입력하신 정보는 삭제 대상 확인 및 처리 결과 회신 목적으로만 사용됩니다.

3. 삭제되는 데이터

구분처리 방식
개인정보(카카오 닉네임·프로필 이미지·카카오 회원 식별자·푸시 기기 토큰)완전 삭제 또는 복구 불가능하게 익명화
이용자 생성 콘텐츠(투표·태그·활동·댓글 등)작성자 표시가 ‘알 수 없는 계정’으로 익명화되어 보존(다른 참여자의 기록·집계 보호를 위함)

삭제된 개인정보는 복구할 수 없습니다.

4. 처리 기한

웹으로 접수된 삭제 요청은 요청 접수 후 7영업일 이내에 처리되며, 처리 완료 시 입력하신 연락처로 안내합니다. (앱 내 삭제는 즉시 처리됩니다.)

5. 관련 안내

개인정보의 수집·이용·보관·파기에 관한 자세한 내용은 모아모아 개인정보처리방침을 참고해 주시기 바랍니다.
